## 🔴 INFRAESTRUTURA — o que quebrou e como se contornou

- 🔴 **`mcp__workspace__bash` falhou em 3 tentativas seguidas**, sempre com `failed to mount ... Plan9 share "c" which is not mounted` + `ensure user: user dazzling-optimistic-euler already exists unexpectedly`. Não é intermitência de rede: a VM não sobe. **Toda a rotina foi feita com Desktop Commander (PC ligado).** Se repetir, ir direto ao shell local em vez de gastar tentativas.
- 🔴 **`start_process` COME o `$` de comandos PowerShell inline.** `powershell -Command "$PAT=..."` chega ao shell como `=...` e o parser quebra. **Sempre escrever o script em arquivo com `write_file` e executar com `-File`.** Vale para PowerShell e para cmd — é a mesma regra que o SKILL já dá para o `.bat` das transcrições, e ela vale para o pipeline todo.
- 🔴 **`timeout /t N /nobreak >nul` não funciona dentro do Desktop Commander** ("não há suporte para o redirecionamento de entrada"). Os downloads passaram assim mesmo, mas o espaçamento antibot não aconteceu. **Trocar por `ping -n <N+1> 127.0.0.1 >nul`.**
- 🟡 **Prints com acento estouram no cmd (cp1252).** `UnicodeEncodeError` ao imprimir a saída de subprocesso. Gravar o log em arquivo UTF-8 e imprimir com `.encode('ascii','replace')`, ou abrir o console com `chcp 65001`.
- 🔴 **`compose-capa.py` tem os caminhos de fonte HARDCODED em Linux** (`/usr/share/fonts/truetype/dejavu/`). No Windows o Python resolve isso para `C:\usr\share\fonts\truetype\dejavu\`, que não existia, e o script **aborta** (nem o `--allow-fallback` salva, porque a fonte padrão mora no mesmo diretório). 🟢 **Resolvido de forma permanente: baixei o DejaVu 2.37 oficial e gravei as 4 fontes em `C:\usr\share\fonts\truetype\dejavu\`.** Não precisa repetir. **Rodar o compose com o cwd em `C:\`** (`cd /d C:\ && python ...`), senão o `/usr/...` resolve para a raiz de outro drive.
