## 🔧 INFRAESTRUTURA — o que quebrou e como se contornou

- 🔴 **`mcp__workspace__bash` falhou em 2 tentativas, com o MESMO erro de 10/09** (`Plan9 share "c" which is not mounted` + `user ... already exists unexpectedly`). A mensagem do runtime agora nomeia a causa: **atualização do Windows de 8 de setembro**. **Trate como estado permanente até prova em contrário: gaste no máximo 2 tentativas e vá direto ao Desktop Commander.**
- 🟢 **A rota boa no shell local é uma SESSÃO PERSISTENTE, não `powershell -Command` inline.** `start_process("powershell.exe -NoProfile -NoLogo")` devolve um PID; daí em diante use `interact_with_process`. **Nessa sessão o `$` NÃO é comido** — `$PAT`, `$API`, `$hdr` sobrevivem entre chamadas e o estado persiste a rodada inteira. A regra de 10/09 ("start_process come o `$`") vale só para `powershell -Command "..."` inline.
- 🔴 **ACENTO PASSADO INLINE PELO POWERSHELL PARA O PYTHON CHEGA COMO MOJIBAKE.** `--kicker "CAFÉ COM MERCADO · SEXTA"` virou `CAF╞ë COM MERCADO ╤À SEXTA` e `deflação` virou `defla╞º╞úo` **na capa publicada**. O defeito é silencioso: o script retorna `OK`, sem aviso nenhum. 🟢 **Corrigido na origem:** `_rodar_compose.py`, gravado em UTF-8 com `write_file`, que chama o compose por `subprocess` — no Windows isso usa `CreateProcessW` (wide) e preserva os acentos. **Nunca mais passe texto com acento como argumento inline; escreva um launcher.** A regra já foi para o SKILL.md.
- 🟡 **Só se descobre o mojibake OLHANDO a capa.** Salvar a capa composta como thumbnail na pasta de outputs e ler com `Read` virou passo obrigatório antes do PUT.
- 🔴 **A raiz `C:\` não é gravável** (`UnauthorizedAccessException`). Grave os scripts auxiliares na pasta do projeto e use `cd C:\` **apenas para o cwd**, que é o que faz o `/usr/share/fonts/...` do compose resolver para `C:\usr\share\fonts\...`. As fontes DejaVu continuam lá (confirmado).
- 🟡 **O Python do PC é o 3.12.7 no PATH, não o `C:\Python313` do snapshot antigo.** O **Pillow não estava instalado** — `pip install pillow` antes de compor. `yt-dlp` idem.
- 🟢 **RSS do YouTube pelo PowerShell resolve.** `Invoke-WebRequest` + `[xml]` + `Sort-Object updated -Descending` num `.ps1` gravado em arquivo. Mais rápido e mais confiável que o subagente. **Rota preferencial enquanto o bash estiver fora.**
